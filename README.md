# Proyecto Sprint 7  
## Análisis Exploratorio de Datos aplicado a la identificación de riesgos y soporte a decisiones de negocio.

### 👩‍💼 Rol
Analista de datos

### 🧩 Contexto del proyecto
En contextos de negocio, especialmente en modelos digitales, muchas decisiones se toman con información parcial o sin una comprensión clara de los riesgos operativos y financieros.  
Este proyecto se centra en el uso de **Análisis Exploratorio de Datos (EDA)** como herramienta para entender el comportamiento de los datos antes de tomar decisiones estratégicas.

---

## 🎯 Objetivo
- Analizar un dataset estructurado desde una perspectiva de negocio.
- Identificar **patrones, outliers y variables críticas**.
- Detectar posibles **riesgos operativos o financieros**.
- Generar insights que apoyen la **toma de decisiones informada**.

---

## 🔍 Enfoque de análisis
El análisis se desarrolló bajo un enfoque práctico orientado a negocio:

- Limpieza y preparación de datos.
- Análisis exploratorio para entender distribuciones y relaciones.
- Identificación de valores atípicos y comportamientos no esperados.
- Visualización de variables clave para facilitar la interpretación.

El foco no fue únicamente técnico, sino en **qué significan los datos para la operación y el riesgo del negocio**.

---

## 🛠️ Herramientas utilizadas
- **Lenguaje:** Python  
- **Librerías:** pandas, NumPy  
- **Visualización:** Matplotlib, Seaborn  
- **Entorno:** Jupyter Notebook  

---

## 📊 Resultados y hallazgos
- Se identificaron **patrones relevantes** en el comportamiento de los datos.
- Se detectaron **outliers** que pueden representar riesgos o situaciones excepcionales.
- El análisis permitió comprender mejor qué variables tienen mayor impacto en la operación.

Estos hallazgos ayudan a **anticipar riesgos** y a evaluar escenarios antes de escalar decisiones financieras u operativas.

---

## 💡 Conclusiones
El Análisis Exploratorio de Datos es una etapa clave para:
- Reducir incertidumbre.
- Evitar decisiones basadas únicamente en intuición.
- Comprender la calidad y límites de la información disponible.

Este proyecto demuestra cómo el EDA puede utilizarse como una herramienta de **prevención de riesgo y soporte a decisiones de negocio**, más allá de un ejercicio técnico.
